# Contributing

Thanks for helping improve the OpenAgents World procedural demo.

## Before opening a change

1. Keep the repository frontend-only and procedural.
2. Do not add production code, endpoints, credentials, user data, operational state, payment logic, administration tools, or third-party assets without clear license and provenance records.
3. Install the pinned dependencies with `npm ci`.
4. Run `npm run check` and `npm run build`.
5. Describe the user-visible effect and validation performed in the pull request.

Small, focused pull requests are easier to review. For larger ideas, start a thread in [GitHub Discussions](https://github.com/openagentsworld/community/discussions).
